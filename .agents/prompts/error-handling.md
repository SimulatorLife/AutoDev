# Improve error-handling consistency

Review the codebase and pinpoint an area where error handling is inconsistent, ad-hoc, or missing. Refactor that area to align with a consistent project-wide pattern—whether through standardized logging, safe fallbacks, or structured error reporting—so issues are easier to diagnose and handle without unnecessary complexity.

Before editing, discover the target repository's documented conventions and validation commands. Do not assume a particular language, package manager, framework, directory layout, or fixture format. Keep the work to one bounded change, preserve unrelated work, and never weaken tests or add compatibility shims.
