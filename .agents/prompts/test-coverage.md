# Improve test coverage and quality

Select one coherent area of the target repository where coverage or test reliability is insufficient. Discover the repository's own test conventions, then add or expand focused automated tests for expected and edge-case behavior, or repair a weak test when that is the higher-value improvement. Keep the suite deterministic, fast, and behavior-focused; do not rewrite the entire suite, duplicate production logic, or weaken existing requirements. Run the affected tests and the repository's documented validation commands before finishing.
